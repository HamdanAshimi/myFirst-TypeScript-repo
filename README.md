# TypeScript Todo App

My first React + TypeScript project. This application demonstrates the fundamentals of building React components with TypeScript by allowing users to add and delete todo items.

## Features

- Add new todos
- Delete existing todos
- Built with React and TypeScript
- Simple and beginner-friendly codebase

## Technologies Used

- React
- TypeScript
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open your browser and visit:

```text
http://localhost:3000
```
